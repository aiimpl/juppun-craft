# じゅっぷんクラフト

パラシュートで降りて、集めて、作って、戦う。最後の1人がドン勝の、ブラウザで遊べる最大4人のブロック・バトロワです。
部屋を作ってリンクを送るだけで、友達が同じ島に入れます。

**ブラウザで遊ぶ：https://aiimpl.github.io/juppun-craft/**

## ルール
- 島は試合ごとに自動で生成します（128×128ブロック。平原・森・砂浜・洞窟・鉱石）
- 全員がパラシュートで島の四隅の上空から降下します（降下中は後ろからの視点、着地すると目線の視点に固定）
- 最初の2分は準備時間で、攻撃はできません
- 3分から赤い安全地帯が、ランダムな中心に向かって狭まります。外にいると体力が減り、時間がたつほど強くなります
- 倒されたら脱落して観戦になります。持ち物はその場に落ちます
- **最後の1人がドン勝**。10分で決着しなければ、生き残りのうち倒した数が多い人の勝ちです
- 定員は4人です。5人目からは観戦しながら待ち、次の試合から入れます（待っていた人が先に入ります）

## マイクラに合わせた部分
- **採掘**：採掘時間は「道具の速さ ÷ 硬さ ÷ 30（取れない場合は100）」、1ティック＝1/20秒で計算します。素手で丸太を掘ると3秒、石は素手では何も落ちません。10段階のひびが入り、空中や水中では遅くなります
- **アイテム**：壊したブロックは地面に落ち、0.5秒たつと近くの人に吸い寄せられます。Q で捨てられます
- **持ち物画面**：防具4マス、2×2のクラフト、持ち物27マス、ホットバー9マスです。操作もマイクラと同じで、アイテムをつかんで置く、右クリックで半分に分ける・1個ずつ置く、つかんだまま複数のマスをなぞって均等に分ける（右ボタンなら1個ずつ）、ダブルクリックで同じ物を集める、Shift＋クリックでまとめて移す、ができます
- **クラフト**：作業台の3×3に並べた形で決まります（つるはし・斧・シャベル・剣 × 木／石／鉄／ダイヤ、防具4部位 × 鉄／ダイヤ、弓、矢、かまど など31種類）
- **かまど**：材料と燃料を入れると焼けます（鉄鉱石→鉄インゴット、砂→ガラス、丸石→石、原木→石炭）。燃料は石炭・原木・木材・棒です
- **戦闘**：振りのため時間でダメージが変わり、落下中に当てるとクリティカル（1.5倍）です。走りながら当てるとノックバックが強くなります。防具は1ポイントにつき4%ダメージを減らします。道具と防具には耐久値があります
- **動き**：歩く3.7、走る5.2、しゃがむ1.3（ブロック/秒。マイクラより少し遅め）。しゃがむと足場の端から落ちません。満腹度は走る・跳ぶ・攻撃で減り、18以上で体力が回復します
- **表示**：一人称の腕振り、攻撃を受けると画面が傾いて相手が赤く光る、倒されると横に倒れる

### 10分の試合に合わせて変えた部分
- かまどで1個焼く時間は5秒です（マイクラは10秒）
- 葉からりんごが落ちる確率は5%です（マイクラは0.5%）
- 動物や敵は出ません。糸はクモの巣から、火打石は砂利から取れます
- 矢は「火打石・棒」の2つでも作れます（羽根がないため）

## キャラクター
スティーブではなく、オリジナルの6体（たぬき・きつね・にんじゃ・ロボ・かっぱ・ペンギン）から選べます。

## 操作
| PC | スマホ | 内容 |
|---|---|---|
| W A S D | 左下のスティック | 移動 |
| Space | 跳ぶ | ジャンプ |
| Ctrl／W を2回 | スティックを奥まで | 走る |
| Shift | しゃがむ | しゃがむ |
| 左クリック | 攻撃（長押しで掘る） | 攻撃・掘る |
| 右クリック | 置く／使う | 置く・作業台やかまどを開く・食べる・弓を引く |
| E | 持物 | 持ち物画面 |
| Q | 捨てる | 手に持った物を捨てる |
| 1〜9／ホイール | ホットバーを押す | 持ち替え |

## 通信の仕組み
- ブラウザ同士を WebRTC で直接つなぎます。部屋を作った人のブラウザが中継役です（サーバーはありません）
- つなぐ相手を見つけるときだけ、PeerJS の公開サーバー（0.peerjs.com）を使います
- 会社や学校のネットワークなど、直接つながれない環境では入れないことがあります
- 部屋を作った人がページを閉じると、部屋はなくなります

手元で動かす場合は、ESモジュールを読み込むためローカルサーバー経由で開いてください（例：`python3 -m http.server` → http://localhost:8000）。
